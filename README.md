# 📊 HR Analytics Dashboard

An interactive **HR Analytics Dashboard** built using **Power BI, DAX and Excel** to analyze workforce data and generate actionable insights for workforce planning and management decision-making.

---

## 📌 Project Overview

This project analyzes HR data covering **1,470 employees** and provides insights into workforce composition, promotions, retrenchment, satisfaction, overtime and role-level trends.

The dashboard transforms raw HR datasets into interactive visualizations and KPIs that help understand employee performance and workforce trends.

---

## 🎯 Project Objectives

- Analyze overall workforce composition
- Identify promotion-ready employees
- Identify employees flagged for retrenchment
- Analyze employee satisfaction
- Analyze overtime trends
- Compare workforce trends across roles and departments
- Build interactive dashboards for HR decision-making
